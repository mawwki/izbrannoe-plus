# Избранное+ — умное «Сохранённое» для Telegram

Бот-«второй мозг» для [@favorites_plus_bot](https://t.me/favorites_plus_bot): пересылайте ему
всё что угодно — он сам классифицирует, тегирует, распознаёт даты и находит сохранённое
по первому запросу. Управление и настройка — в десктоп-программе.

Сделано «по умнее» прототипа из анкеты «Мыслехват» (хакатон): вместо GPU-инференса —
**лёгкий локальный классификатор + бесплатные decision-модели OpenRouter**, вместо ручных
папок — **самообучение на правках пользователя**.

## Возможности

| | |
|---|---|
| 🗂 Автоклассификация | гибрид: локальный TF-IDF+LogReg (офлайн, мгновенно) → при уверенности ниже порога запрос к `perplexity/pplx-decider-flash-v1.3:free` → фолбэк `perplexity/pplx-decider-v1.3:free` / `respan/span-01-lite:free` через [Decisions API](https://openrouter.ai/docs/guides/features/decisions) |
| 🏷 Самообучение | кнопка «Не то» под карточкой → правка запоминается, локальная модель **дообучается на ходу** |
| 🔍 Гибридный поиск | BM25 (SQLite FTS5) + векторный TF-IDF с русским лёгким стеммингом: «нейронные сети» найдут «нейронным сетям» |
| 🤖 Ответы по смыслу | `/ask` — RAG по заметкам через бесплатный `openrouter/free` с номерами источников |
| 📅 Распознавание дат | «в пятницу в 19:00», «25.12», «завтра» → `/upcoming` |
| 🌅 Дайджесты | `/digest` за сегодня + ежедневный по расписанию (настраивается в программе) |
| 📎 Медиа | фото, голосовые, видео, документы, стикеры хранятся с file_id — выдаются обратно из поиска |
| 📊 Статистика | `/stats` с барчартом по категориям, `/list` — browse с пагинацией |

## Программа настроек (PyQt6)

Dark-glass glassmorphism по спецификации [pyqt6-gm-ui](https://github.com/mawwki/pyqt6-ui-skills):
дышащий градиентный фон с оранжевым свечением (#F97316), стеклянные карточки с настоящим
backdrop-blur, сайдбар-пилюля с анимированным индикатором, светофор-кнопки окна,
оранжевые тумблеры/слайдеры/сегменты, живой лог бота, проверка токенов, редактор категорий
и критериев для классификатора, запуск/останов/автозапуск бота, светлая/тёмная темы.
Настройки применяются с автоперезапуском бота.

```bash
python run_gui.py    # программа настроек (запустит бота, если включён автозапуск)
python run_bot.py    # бот отдельно
```

## Команды бота

- `/start`, `/help` — справка
- `/find запрос` — гибридный поиск
- `/ask вопрос` — ответ по заметкам через ИИ
- `/list` — категории, `/stats`, `/upcoming`, `/digest`, `/clear`

## Структура

```
favorites_plus/   config · storage (SQLite+FTS5) · classifier (гибрид) ·
                  llm (openrouter/free) · search (BM25+TF-IDF) · bot (aiogram 3)
gui/              theme (глянцевая палитра) · widgets (MD3) · bot_manager · main
tests/            test_core (33) · test_bot_e2e (12) · smoke_gui (21) → assets/_qa/
```

## Замечания

- Голосовые сохраняются как медиа без расшифровки (тяжёлый ASR сознательно не тащится —
  можно добавить позже).
- Бесплатные модели OpenRouter лимитированы: при 429 включается retry и фолбэк-цепочка,
  а режим «Гибрид» сводит обращения к модели к минимуму.
- Данные лежат локально: `data/favorites.db`, конфиг — `config.json`.
